Manual Server Control Required

To change the list or select a winner, you must perform these steps **on the Server Computer (10.10.5.28)**:

  1. Open the **data.json** file in a text editor (Notepad, VS Code).
  2. **To change names:** Edit the "participants" array.
  3. **To set the winner:** Change the value of "selectedWinner" to the desired name (e.g., "selectedWinner": "Jasmina").
  4. **Save** the data.json file.
  5. The Display computer will update automatically.
